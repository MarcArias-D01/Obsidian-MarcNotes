Notas : Puede derivarse de un correctivo o preventivo. No finaliza la reparación y queda pendiente otra tarea. Acaba derivando en una acción correctiva.
Avisos : Llamada del cliente por mal funcionamiento. Correctivo.

Diagnóstico: Una vez reparado, intentar sintetizar lo que ha hecho.
	- Sub-diagnóstico: solo si hay algún código de error. sus propios ascensores.

Si hay muchos cierres directos algo esta mal.
Podemos tener varias cadenas de acción. para el mismo aviso. Debería ser así siempre.

Un flujo correcto seria primero Diagnostico X acción comprobar --> diagnostico X acción reparar.

Cierre directo: Acceso de carga por sobrecarga. Reset y ya funciona todo. Debería tener una acción o algo que determine todo esto. No diagnostico de ascensor funcionando.

En muchos casos si tienes un diagnostico debería tener un componente y zona.
